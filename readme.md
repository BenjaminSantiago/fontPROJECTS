# FONT PROJECTS

This is the repository where I work on fonts, largely via Fontra or scripting with tools like FontParts or Python scripts. I need to re-organize the folder a bit to separate more functional output, working files, and demos/tests. 

I want to have a better way to showcase them on my teaching website professorbenjamin.biz as they are usually the product of classwork.

Recent output includes: 
- "demo-er" --> A variable uppercase alphabet to test the concept of translation as a function of ellipses changing width and rotation.

a demo is available here: 
https://professorbenjamin.biz/html/DES3440__S26__Translation/index.html

- Ramon Tejada Workshop --> Sara Duell and I hosted Ramon Tejada for a workshop for our sections of Junior Seminar at Purchase College, SUNY. Students produced letters which are compiled into a .ttf. It has glyph cycling to view the letter options, or you can explicitly select alternates. 
- "Freakmaxxxing" --> A two-axis variable font created as an exercise in an introduction to type design course called Typographic Investigations. It has a closer to normative "weight" axis and an arbitrary "freakiness" axis.
- "Lost + Found" --> A font based on the handwriting of Lindsay Stewart for the Senior Thesis Exhibition at Purchase College, SUNY in 2026. It includes glyph cycling to increase the handdrawn appearance and has punctuation and basic kerning (mostly for English words).
- "REKT STAKT" --> A variable font made to test the idea of a font that is never fully "static." It is designed with a variable usage in mind. It is based on three columns of five squares, where each column gets an axis to control its width.
